# Sales Dashboard Reporting

## Dashboard Overview

This dashboard project analyzes:
- sales performance
- regional trends
- profitability metrics
- customer behavior
- business KPIs

The dashboard was developed using Tableau Public while following Power BI business intelligence reporting principles.

---

## Dashboard Pages

### 1. Executive Overview
High-level KPI reporting and sales trend analysis.

### 2. Regional Analysis
Regional sales and profitability comparisons.

### 3. Profitability Insights
Analysis of low-margin products, discount impact, and loss-making categories.

---

## Key KPIs

- Total Sales
- Total Profit
- Profit Margin %
- Total Orders
- Total Customers
- Average Order Value

---

## Dashboard Features

- Interactive visual analysis
- KPI monitoring
- Profitability tracking
- Regional comparison
- Executive-style business reporting
